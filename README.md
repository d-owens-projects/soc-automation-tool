# soc-automation-tool
PowerShell Base64 Decoder with risk scoring, JSON output, quiet mode, and batch folder processing.

A Python-based automation engine designed to streamline Security Operations Center (SOC) workflows. This tool processes suspicious indicators, decodes encoded data, scores risk levels, and generates structured JSON reports to support faster and more efficient incident triage.

🧩 Components
Base64 Decoding
Indicator Extraction (IPs, Domains, Hashes)
Risk Scoring & Severity Classification
Batch Mode Processing
Structured JSON Reporting

🧰 Technologies Used
Python
JSON for structured output
Rule-based detection logic
Modular architecture for future expansion

How to Run
python soc_automation_tool.py

Output
output/report.json
